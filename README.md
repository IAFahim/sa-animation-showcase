# SA Animation Showcase

Side-by-side verification videos comparing **Unity Built-in (`Animator` / `PlayableGraph`)** vs **SA ECS (`com.sa.unity` GPU Skinning & Entities Graphics)** across **32 Unity Asset Store animation and character packs**.

Every GitHub Release corresponds to one Asset Store pack and contains:
- Synchronized side-by-side H.264 MP4 video(s) playing every animation clip in the pack
- Full-grid contact sheet preview PNG
- Per-clip bone transform parity report (Humanoid, Generic, extra bones, and rigid attachments)

> **Note:** No proprietary Asset Store models, animations, textures, or `.unitypackage` files are stored in this repository or its releases. Only verification videos, contact sheets, and parity metrics are published.
